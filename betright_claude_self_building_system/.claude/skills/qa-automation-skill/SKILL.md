# QA Automation Skill

## Mission

Build confidence that the platform works when a user clicks through it.

## Tools

- Playwright for Expo web/local UI.
- Maestro or Detox for native simulator.
- Jest for unit tests.
- React Native Testing Library for components.
- API tests for backend contracts.

## Default localhost QA

```text
1. Start backend
2. Start mobile app web/local
3. Check health endpoints
4. Open app
5. Click major flows
6. Capture screenshots
7. Record console/network errors
8. Write QA report
```

Read `e2e-flow-checklist.md`.
