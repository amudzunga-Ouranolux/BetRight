# BetRight Design System Skill

## Themes

1. Lime Premium
   - dark background
   - lime primary
   - sports stadium glow
   - premium black cards

2. Ocean Mint
   - light background
   - teal/mint primary
   - soft cards
   - clean analytics feel

3. Red Energy
   - dark/black background
   - red primary
   - strong contrast
   - aggressive sports energy

## Rules

- Use theme tokens.
- Do not hard-code colours.
- Design mobile-first.
- Keep components compact.
- Use clear hierarchy.
- Include loading, empty, and error states.
- Avoid gambling-promotional language.

See `theme-tokens.md` and `components.md`.
