# MVP Scope

## Include

- Authentication UI
- Onboarding
- Three themes
- Home
- Favourites
- Matches
- Match Detail
- Manual Predict
- Saved Predictions
- Prediction History
- Profile/Settings
- Notifications
- Basic model performance screen
- QA automation
- CI/CD pipelines

## Exclude

- Real-money betting
- Bet placement
- Wagering
- Gambling odds integration
- Gambling wallet/payment flows
- High-risk push copy
