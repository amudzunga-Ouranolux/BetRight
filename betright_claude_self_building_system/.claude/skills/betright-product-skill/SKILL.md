# BetRight Product Skill

## Product positioning

BetRight is an AI sports prediction analytics platform.

Allowed:
- match predictions;
- likely scorelines;
- confidence;
- expected goals;
- saved predictions;
- model performance;
- AI insights;
- notifications about predictions and match changes.

Not allowed:
- real-money betting;
- wagering;
- sportsbook integrations;
- odds scraping;
- bet placement;
- funding accounts;
- guaranteed-win language.

## Core user flow

```text
Choose interests
→ See personalised upcoming matches
→ Open prediction breakdown
→ Run manual prediction
→ Save predictions
→ Track model accuracy
```
