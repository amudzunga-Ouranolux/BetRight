# ML Training Pipeline Skill

## Rules

- Use time-based validation.
- Prevent data leakage.
- Store feature snapshots.
- Track model versions.
- Track calibration.
- Track confidence bucket accuracy.
- Compare baseline vs ML.
- Do not deploy a model without evaluation.

Read `anti-leakage.md` and `evaluation.md`.
