# Security and Compliance Skill

## Hard product boundary

Do not build:
- wagering;
- bet placement;
- gambling wallet;
- sportsbook integration;
- odds scraping;
- gambling provider onboarding;
- guaranteed-win claims.

## Required wording

Use:
- AI prediction;
- confidence;
- saved prediction;
- analytics;
- model performance;
- match intelligence.

Avoid:
- guaranteed;
- sure win;
- risk free;
- easy money;
- place bet;
- deposit;
- cash out.

Read `responsible-use-rules.md`.
